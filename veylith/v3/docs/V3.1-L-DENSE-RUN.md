# v3.1-L bounded Dense-Combined training run

Status 2026-10-27. **Completed all 500 optimizer updates with exit code 0.** No
GPU fault, HIP error, GPU reset, OOM, non-finite value or router collapse
occurred. The 12 GiB peak-reserved-VRAM guard was never approached: the peak
was 6.107 GiB.

This is a 500-update bounded run on 16,352,000 CE targets, not a full-corpus
training result. It shows that the configuration trains stably for this
horizon and that validation improves monotonically over it. It does not
establish long-run stability, convergence or generalization.

## 12. Stop reason, warnings and deviations

Stop reason: **500 of 500 updates completed, exit 0.** No guard, fault or
limit fired.

Deviations and warnings:

- **Executed HEAD.** Preflight was `6ba3558` as required. The authorized
  minimal telemetry and time-budget change to `veylith/v3/training/train.py`
  was committed as `ae00feb` before the GPU run, so the executed code is
  `ae00feb`, not `6ba3558`. The change does not touch the architecture, data,
  optimizer, routing or checkpoint format.
- **The 12 GiB limit was never close.** The peak reserved value is 6.107 GiB
  and the peak allocated value is 5.568 GiB. Headroom over the limit stayed
  above 5.8 GiB. The limit is therefore untested as a real constraint.
- **Near-uniform routing.** Balanced and stable, but not specialized. See
  section 9.
- **Step-500 training loss.** Slightly above step 400. Validation improved at
  the same step.
- **Import diagnostic.** `(null): No such file or directory` still appears at
  import time, as in v3.1-I and v3.1-K. It is non-fatal and was not the cause
  of any stop.
- **Sparse path untouched.** The BF16 Sparse-MoE safety guard stayed enabled
  and no sparse execution occurred. `--moe dense` was used throughout.
- **No retry, no second run.** One GPU process, one bounded experiment.
- **Scope.** 500 updates, 16.35M CE targets, one seed. Macro CE is still
  falling at the end. Nothing here establishes full-corpus convergence, final
  model quality or generalization to held-out data.
