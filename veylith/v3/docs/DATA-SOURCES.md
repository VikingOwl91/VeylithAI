# v3 data sources and licenses

Checked on 2026-10-26 against the Hugging Face API and the datasets-server.
The repository does not redistribute any source text; the pilot corpus stays
outside git.

is not a safety or factuality filter.

published, attribute the FineWeb/FineWeb-Edu dataset and keep the license
notice. The manifest of every corpus records the license id; the local
pilot is not published.

## Access and credentials

Public sources need no token. For a gated dataset, log in with Hugging
Face's own tooling (`huggingface-cli login`); the credential stays in Hugging
Face's store. The pipeline never reads `HF_TOKEN`, never writes it to a
manifest or log, and never prints request headers. HTTP 401/403 is reported
as an access error with a pointer to that login, exit code 2.

## Backends

| backend | mechanism | dependency | use |
|---|---|---|---|
| `http` (default) | datasets-server `/rows`, 100 rows per request, `revision` pinned, bounded retries | none | pilot, constrained environments |
| `datasets` | `datasets.load_dataset(..., streaming=True)` | `datasets` (not installed in the system Python) | scale path |

The rows API is paginated and rate limited. The 10M pilot read 11,754 rows
in 119 pages with 2.5 s pacing and no 429. An immediate second full
2000-document materialization in the earlier session hit HTTP 429 after
three bounded retries (exit 3, no partial manifest). Long runs should use the
`datasets` backend or space requests out. HF streaming order is not a stable
contract across library versions; the pinned revision plus the local
manifest is the reproducibility anchor.

### Wikipedia

- License: CC BY-SA 3.0 and GFDL (dataset card; dumps legal page). Attribution
  and share-alike obligations apply to redistribution of the text.
- Schema: `id` (page id), `url`, `title`, `text`. English, dump 2023-11-01.
- Documents are long (median tens of KB); the per-source filter allows up to
  100,000 characters.
- Risks: public encyclopedia text, but PII can appear in articles; individual
  article licensing can vary (the card notes some text is CC-only, some
  public domain). The local corpus is not published.

### Cosmopedia v2

- Dataset: `HuggingFaceTB/smollm-corpus`, config `cosmopedia-v2`.
- License: ODC-By 1.0 per the corpus card.
- Provenance: synthetic textbooks, blog posts and stories generated by
  Mixtral-8x7B-Instruct-v0.1 from FineWeb web seeds; fields `prompt`, `text`,
  `token_length`, `audience`, `format`, `seed_data`. No `id` column, so the
  document key uses `sha256(text)[:32]`.
- Risks: hallucinations, stale facts, model-specific style, and potential
  semantic overlap with FineWeb seeds. It is 15.9 % of the 100M train tokens.

### Python-Edu (blocked)

- The HF config contains metadata only (`blob_id`, `repo_name`, `path`,
  `length_bytes`, `score`, `int_score`), no text.
- The SmolLM card says file contents come from the Software Heritage S3
  bucket and refers to The Stack v2 for the license.
- The Stack v2 is gated (`license: other`, `gated: auto`); its dataset card is
  not accessible without accepting terms (HTTP 401 on 2026-10-26). No terms
  were accepted on the user's behalf.
- Consequence: the 5 % Python-Edu share is missing from the 100M corpus. It
  is reported, not backfilled. Adding it requires a terms review, acceptance
  by the user, and an S3 fetch path with the Stack v2 license metadata.

### Adding a source

1. Record dataset id, config, split, revision sha, license and access in
   `sources.py` and the manifest.
2. Implement a streaming adapter yielding `SourceDocument` with a stable
   `doc_key`; never read a token.
3. Check the schema on a bounded sample; drift raises a typed error.
4. Add a license note here and an offline test with a fake source.
5. For share-alike sources, decide how the derived corpus is licensed before
   redistribution.

Requirements for adding a source:

1. Record the dataset id, config, split, revision sha, license and access
   mode in `sources.py` and the manifest.
2. Implement a streaming adapter that yields `SourceDocument` with a stable
   `doc_key`; never read a token.
3. Check the schema against a bounded sample; schema drift must raise a
   typed error.
4. Add a license note to this file and an offline test with a fake source.
5. For share-alike sources (for example Wikipedia), decide explicitly how
   the derived corpus is licensed before redistribution.

## Corpus handling

- Normalization: NFC, CRLF to LF, control characters removed, trailing
  spaces stripped, 3+ blank lines collapsed. Content is otherwise unchanged.
- Filters: minimum and maximum length, replacement-character ratio, letter
  ratio, language and language score, `int_score >= 3` when present.
- Deduplication: exact and near-identical, global over the staged set; the
  kept document is the one with the smallest `doc_key`.
- Splits: pure function of `doc_key`, test < test_permille, validation <
  test+val permille, train otherwise. The 10M pilot used 10/10 (98 / 1 / 1);
  each run records its values in the manifest. Never assign splits by
  arrival order.
- The tokenizer is trained on final train-split documents only.
