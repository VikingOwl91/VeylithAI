The bounded Dense-Combined experiment did **not** complete. The environment
had no GPU fault and remains healthy, but the 6 GiB peak-reserved-VRAM target

- no 500-update result,

A second GPU training attempt requires new authorization. Before it:

1. Decide whether the 6 GiB target applies to allocated or reserved memory.
2. If reserved, use an explicit higher reserved target or a lower-memory

   resumable state.
